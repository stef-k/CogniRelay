# CogniRelay v1.4.15 Release Notes

Release date: 2026-10-23

Deployment and install instructions now authenticate the very first pip
download using the Python advisory's pip 26.2.2 wheel and pinned SHA-256.
Dependency installation follows only after that succeeds. Development and
release requirements also require certifi >=2026.10.19 (#315).

The [TLS audit and recovery guide](../python-tls-security.md) records the
runtime/system trust paths, exact observed versions, artifact scope, and
existing-environment repair instructions. The source/sdist includes the
deployment fix; wheel metadata carries the corrected installation guide.
CogniRelay does not bundle a Python runtime or CA store. Operators must
update host certificates and existing venvs separately. No production
deployment or exploitation is claimed by this release.

Continuity storage, credentials, service wiring, rollback, and API behavior
are unchanged.

<artifact-directory>` and validate both with `python -m twine check
<artifact-directory>/*` using the bootstrapped release environment.
